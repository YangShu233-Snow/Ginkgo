# Ginkgo

一个Markdown文档静态网站构建框架，探索历年卷传承的新方式。

## Feature

1. 从特定格式要求的 Markdown 文档开始，自动构建一个可以立即部署于任何服务器上的静态网站框架。
2. 将历年卷题目转化为在线交互的选择题与问答卡，提供更多历年卷传承方式。
3. 支持快速部署至 Github Pages，让协作传承更简单。
